# 계정별 분석 정보 복원

`GET /api/me/analysis-profile` → `{ accountId, revision, profile }`. 처음에는 revision 0, profile null.
`PUT /api/me/analysis-profile` → 같은 구조의 요청/응답. 로그인, 현재 필수 약관 동의, CSRF 토큰 필요.

profile은 이름·생년월일·성별·양음력·윤달·출생시간·분석 완료 여부·친구 명단·명단 확인 시각만 받습니다. 구매/인증 상태는 저장하지 않습니다. 결과는 입력 정보로 프론트에서 재계산합니다. 새 분석을 완료하면 최신 분석을 대체하며 과거 분석 목록은 아닙니다.

계정은 세션으로 결정합니다. 요청 accountId가 현재 세션과 다르면 PROFILE_ACCOUNT_CHANGED(409). 다른 창에서 먼저 저장해 revision이 바뀌면 PROFILE_CONFLICT(409). 최신 정보를 불러온 뒤 수정해야 합니다.

V1_1 마이그레이션이 계정별 행을 생성할 테이블을 추가합니다. 기존 V1 환경과 후속 결제 마이그레이션을 포함한 환경에서 사용할 수 있습니다. 탈퇴 시 삭제합니다.

프론트는 로그인 시 먼저 조회하며, 완료한 게스트 분석을 로그인한 계정에 옮기거나 저장된 계정 정보를 복원합니다. 기존 로컬 정보는 원래 브라우저에서 로그인해야 서버로 이전할 수 있습니다. 서버 저장에 성공하기 전 다른 기기로 이동한 정보는 복원할 수 없습니다.

배포 순서: 백엔드 배포 완료 → 프론트 배포. 환경변수 추가 없음. 두 브라우저에서 같은 카카오 계정으로 로그인해 이름·입력 정보·무료 결과·명단 복원을 확인합니다. 다른 계정 분리, 로그아웃 후 재로그인, 탈퇴 후 삭제도 확인합니다.
